FreightFlow

Freight Forwarding Management System

ឯកសារណែនាំការប្រើប្រាស់
ទំព័រ · មុខងារ · លំហូរវិក្កយបត្រ និងការទូទាត់

រៀបចំសម្រាប់៖ អ្នកប្រើប្រាស់ / ប្រតិបត្តិការ / ហិរញ្ញវត្ថុ

កាលបរិច្ឆេទ៖ ខែកញ្ញា ឆ្នាំ ២០២៦

គោលបំណង៖ ពន្យល់រចនាសម្ព័ន្ធប្រព័ន្ធ និងរបៀបបង្កើតវិក្កយបត្រ រហូតដល់ការទូទាត់

ភាសា៖ ខ្មែរ

១. សេចក្តីណែនាំ

FreightFlow គឺជាប្រព័ន្ធគ្រប់គ្រង Freight Forwarding ដែលភ្ជាប់ពី សម្រង់តម្លៃ (Quotation) → បញ្ជាសេវាកម្ម (Service Order) → ប្រតិបត្តិការ / ឯកសារ → វិក្កយបត្រ និងការទូទាត់។

ចំណុចសំខាន់សម្រាប់វិក្កយបត្រ៖ វិក្កយបត្រត្រូវបានបង្កើតពី Service Order (ឬពីថ្លៃសេវា / Debit Note) បន្ទាប់ពីមានព័ត៌មានអតិថិជន ទំនិញ ចលនា និងថ្លៃសេវាគ្រប់គ្រាន់។

២. រចនាសម្ព័ន្ធប្រព័ន្ធ (ម៉ឺនុយ)

  • Dashboard — ផ្ទាំងគ្រប់គ្រង
  • Quotation Management — គ្រប់គ្រងសម្រង់តម្លៃ
  • Service Order — បញ្ជាសេវាកម្ម
    • General Information — ព័ត៌មានទូទៅ
    • Movement and Cargo Information — ចលនា និងទំនិញ
      • Invoice — វិក្កយបត្រ
      • Shipment Register — ចុះបញ្ជីដឹកជញ្ជូន
      • Bill — វិក្កយបត្រអ្នកផ្គត់ផ្គង់ / Bill
      • Packing List — បញ្ជីវេចខ្ចប់
      • Container and Transportation — កុងតឺន័រ និងដឹកជញ្ជូន
      • Checkpoint Arrival — មកដល់ចំណុចត្រួតពិនិត្យ
      • Final Destination Arrival — មកដល់ទិសដៅចុងក្រោយ
    • Customs Declarations Information — ប្រកាសគយ
    • Document and Attachments — ឯកសារ និងឯកសារភ្ជាប់
    • Financial Information and Payment — ហិរញ្ញវត្ថុ និងការទូទាត់
      • Debit Note — កំណត់ត្រាឥណពន្ធ
      • Customer Payment — ការទូទាត់របស់អតិថិជន
      • Expense and Profit — ចំណាយ និងប្រាក់ចំណេញ
  • Financial — ហិរញ្ញវត្ថុ
    • Payment — ការទូទាត់

៣. លំហូរអាជីវកម្មរហូតដល់វិក្កយបត្រ

Quotation ➔ Service Order ➔ Cargo / Movement ➔ Documents ➔ Invoice ➔ Payment

ជំហានសង្ខេបដើម្បីធ្វើវិក្កយបត្រ

  1. បង្កើត / ទទួលយក Quotation
  2. បម្លែងទៅ Service Order
  3. បំពេញ General Information (អតិថិជន, ទិសដៅ, ប្រភេទសេវា)
  4. បញ្ចូល Movement and Cargo (ទំនិញ, កុងតឺន័រ, ផ្លូវដឹក)
  5. ភ្ជាប់ឯកសារ (Packing List, Bill, Shipment Register, Customs…)
  6. កំណត់ថ្លៃសេវា / Debit Note បើមាន
  7. បង្កើត Invoice ពី Service Order
  8. ផ្ញើអតិថិជន → ទទួល Customer Payment → កត់ត្រា Payment

៤. Dashboard

ផ្ទាំងទិដ្ឋភាពរហ័សសម្រាប់អ្នកគ្រប់គ្រង និងប្រតិបត្តិការ។

  • ចំនួន Quotation កំពុងរង់ចាំ / បានទទួលយក
  • Service Order កំពុងដំណើរការ / បានបញ្ចប់
  • វិក្កយបត្រមិនទាន់ទូទាត់ (Outstanding)
  • ការទូទាត់ថ្មីៗ និងសង្ខេបចំណូល–ចំណាយ
  • ការជូនដំណឹងសម្រាប់ Checkpoint / Destination Arrival

៥. Quotation Management

គ្រប់គ្រងសម្រង់តម្លៃមុនចាប់ផ្តើមសេវា។

មុខងារ

  • បង្កើតសម្រង់តម្លៃថ្មី (អតិថិជន, ទិសដៅ, ប្រភេទដឹក, ថ្លៃសេវា)
  • កែព្រាង / ផ្ញើទៅអតិថិជន / បង្កើតកំណែ (Revision)
  • ទទួលយក ឬបដិសេធ
  • បម្លែងសម្រង់ដែលទទួលយកទៅ Service Order

ច្បាប់៖ មានតែសម្រង់ដែល Accepted ទេ ទើបបម្លែងទៅ Service Order បាន។ កំណែដែលបានផ្ញើមិនគួរកែដោយសម្ងាត់ — បង្កើត Revision ថ្មី។

៦. Service Order

បញ្ជាសេវាកម្មគឺជាកំណត់ត្រាស្នូល។ វិក្កយបត្រ និងឯកសារភាគច្រើនភ្ជាប់ពីទីនេះ។

៦.១ General Information

  • លេខ Service Order
  • អតិថិជន / អ្នកទទួលទំនិញ / អ្នកផ្ញើ
  • ប្រភេទសេវា (Import / Export / Transit…)
  • ច្រកចេញ–ចូល, ឃ្លាំង, ទិសដៅ
  • កាលបរិច្ឆេទចាប់ផ្តើម / គោលដៅ
  • ស្ថានភាពបញ្ជា (Draft / Confirmed / In Progress / Completed)

៦.២ Movement and Cargo Information

ផ្នែកប្រតិបត្តិការ និងឯកសារដឹកជញ្ជូន។

Invoice វិក្កយបត្រអតិថិជន

  • បង្កើតវិក្កយបត្រពី Service Order
  • បញ្ចូលបន្ទាត់ថ្លៃសេវា (Freight, Customs, Handling, Storage…)
  • ពន្ធ / បញ្ចុះតម្លៃ / រូបិយប័ណ្ណ
  • មើលស្ថានភាព៖ Draft → Issued → Partially Paid → Paid
  • បោះពុម្ព / រក្សាជា PDF / ផ្ញើអតិថិជន

Shipment Register

  • ចុះបញ្ជីដឹកជញ្ជូន (លេខដឹក, កាលបរិច្ឆេទ, អ្នកដឹក)
  • ភ្ជាប់ទៅ Container / Route

Bill

  • វិក្កយបត្រឬវិក័យប័ត្រពីអ្នកផ្គត់ផ្គង់ / Carrier
  • ប្រើសម្រាប់តាមដានថ្លៃចំណាយដែលត្រូវបង់ទៅភាគីទីបី

Packing List

  • បញ្ជីទំនិញ / កញ្ចប់ / ទម្ងន់ / ទំហំ
  • ភ្ជាប់ជាឯកសារសម្រាប់គយ និងការដឹក

Container and Transportation

  • លេខកុងតឺន័រ, ប្រភេទ, Seal
  • រថយន្ត / កប៉ាល់ / ជើងហោះហើរ
  • កាលវិភាគចេញ–មកដល់

Checkpoint Arrival

  • កត់ត្រាពេលមកដល់ចំណុចត្រួតពិនិត្យ
  • ស្ថានភាព / កំណត់សម្គាល់ / ភ្ជាប់រូបភាព ឬឯកសារ

Final Destination Arrival

  • កត់ត្រាមកដល់ទិសដៅចុងក្រោយ
  • ជំហានសំខាន់មុនបញ្ចប់ Service Order និងចេញវិក្កយបត្រចុងក្រោយ

៦.៣ Customs Declarations Information

  • លេខប្រកាសគយ / ប្រភេទប្រកាស
  • កាលបរិច្ឆេទដាក់ / អនុម័ត
  • ស្ថានភាពគយ និងឯកសារភ្ជាប់

៦.៤ Document and Attachments

  • ផ្ទុកឯកសារ (PDF, រូបភាព, Excel…)
  • ភ្ជាប់ទៅ Quotation / Service Order / Invoice / Payment
  • គ្រប់គ្រងកំណែឯកសារ និងសិទ្ធិទាញយក

៦.៥ Financial Information and Payment

Debit Note

  • កត់ថ្លៃបន្ថែមដែលអតិថិជនត្រូវបង់ (ឧ. demurrage, storage, correction)
  • អាចបម្លែង ឬបញ្ចូលទៅ Invoice

Customer Payment

  • កត់ការទូទាត់ពីអតិថិជន
  • ភ្ជាប់ទៅ Invoice (ទូទាត់ពេញ ឬផ្នែក)
  • វិធីទូទាត់៖ សាច់ប្រាក់ / ធនាគារ / ABA / ផ្ទេរ…

Expense and Profit

  • កត់ចំណាយតាម Service Order
  • គណនាប្រាក់ចំណេញ = ចំណូល (Invoice/Payment) − ចំណាយ (Bill/Expense)

៧. Financial → Payment

ម៉ូឌុលហិរញ្ញវត្ថុកណ្តាល សម្រាប់មើល និងគ្រប់គ្រងការទូទាត់ទូទាំងប្រព័ន្ធ។

  • បញ្ជីការទូទាត់ទាំងអស់
  • ត្រងតាមអតិថិជន / Invoice / កាលបរិច្ឆេទ / ស្ថានភាព
  • បែងចែកការទូទាត់ទៅវិក្កយបត្រជាច្រើន (Allocation)
  • មើលសមតុល្យនៅសល់ (Outstanding)

៨. របៀបធ្វើវិក្កយបត្រ (ជំហានលម្អិត)

៨.១ មុនបង្កើត Invoice ត្រូវមានអ្វីខ្លះ?

តម្រូវការ មកពីម៉ូឌុល
អតិថិជន និងអាសយដ្ឋានវិក្កយបត្រ General Information
លេខ Service Order / ឯកសារយោង Service Order
ព័ត៌មានទំនិញ / កុងតឺន័រ (បើត្រូវបង្ហាញ) Cargo / Container
បន្ទាត់ថ្លៃសេវា Quotation / Debit Note / Manual lines
រូបិយប័ណ្ណ និងអត្រាប្តូរប្រាក់ Financial settings / Invoice form

៨.២ ជំហានបង្កើត Invoice

  1. បើក Service Order ដែលត្រូវចេញវិក្កយបត្រ
  2. ចូលផ្នែក Movement and Cargo → Invoice (ឬប៊ូតុង Create Invoice)
  3. ប្រព័ន្ធបង្កើតព្រាងវិក្កយបត្រ រួចទាញព័ត៌មានអតិថិជន និងថ្លៃសេវាពី Quotation/Debit Note
  4. ពិនិត្យ / បន្ថែម / កែបន្ទាត់ថ្លៃ
  5. រក្សាទុកជា Draft
  6. ពេលត្រឹមត្រូវ ចុច Issue / Post ដើម្បីចេញផ្លូវការ
  7. បោះពុម្ព ឬរក្សាជា PDF ផ្ញើអតិថិជន

៨.៣ បន្ទាប់ពីចេញ Invoice

  1. អតិថិជនបង់ប្រាក់
  2. ចូល Customer Payment ឬ Financial → Payment
  3. ជ្រើស Invoice → បញ្ចូលចំនួនទឹកប្រាក់ → វិធីទូទាត់ → កាលបរិច្ឆេទ
  4. ប្រព័ន្ធធ្វើបច្ចុប្បន្នភាពស្ថានភាព Invoice (Partial / Paid)
  5. បើមានចំណាយភាគីទីបី កត់ក្នុង Bill / Expense ដើម្បីមើល Profit

ប្រុងប្រយ័ត្ន៖ វិក្កយបត្រដែលបាន Issue/Post មិនគួរលុបផ្ទាល់។ បើខុស ប្រើ Credit Note / Adjustment / Reverse ដើម្បីរក្សាប្រវត្តិសវនកម្ម។

៩. ស្ថានភាពសំខាន់ៗ

ឯកសារ ស្ថានភាព អត្ថន័យ
Quotation Draft / Sent / Accepted / Rejected ព្រាង → ផ្ញើ → ទទួលយក / បដិសេធ
Service Order Draft / Confirmed / In Progress / Completed ដំណើរការប្រតិបត្តិការ
Invoice Draft / Issued / Partial / Paid / Cancelled ស្ថានភាពវិក្កយបត្រ និងការទូទាត់
Payment Recorded / Allocated បានកត់ត្រា និងបែងចែកទៅ Invoice

១០. តួនាទីណាធ្វើអ្វី (ណែនាំ)

តួនាទី ការងារសំខាន់
Sales Quotation, ទំនាក់ទំនងអតិថិជន
Operations Service Order, Cargo, Container, Checkpoint, Documents, Customs
Finance Invoice, Debit Note, Customer Payment, Bill, Expense & Profit
Manager Dashboard, អនុម័ត, របាយការណ៍ចំណេញ

១១. Checklist មុនចេញវិក្កយបត្រ

  • □ Service Order មានអតិថិជនត្រឹមត្រូវ
  • □ ព័ត៌មានទំនិញ / ដឹកជញ្ជូនគ្រប់គ្រាន់ (បើត្រូវបង្ហាញលើ Invoice)
  • □ បន្ទាត់ថ្លៃសេវាត្រូវបានពិនិត្យ
  • □ Debit Note បន្ថែម (បើមាន) បានបញ្ចូល
  • □ រូបិយប័ណ្ណ និងពន្ធត្រឹមត្រូវ
  • □ ឯកសារភ្ជាប់ចាំបាច់មានរួច
  • □ Issue Invoice → ផ្ញើអតិថិជន → រង់ចាំ Payment

១២. សេចក្តីបញ្ចប់

ឯកសារនេះសង្ខេបម៉ូឌុលទាំងអស់នៃ Freight Forwarding Management System ហើយផ្តោតលើរបៀបទៅដល់ Invoice និង Payment ពី Service Order។

បើត្រូវការបន្ថែម៖ គំរូវិក្កយបត្រ (ទម្រង់បោះពុម្ព), រូបអេក្រង់តាមជំហាន, ឬកំណែអង់គ្លេស — សូមជូនដំណឹង។
